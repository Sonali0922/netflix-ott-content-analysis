# Netflix OTT Content Analysis – Minor Project

This repository contains a minor project based on **Netflix OTT content analysis** using **Microsoft Excel**.  
The project demonstrates essential business analytics skills such as data cleaning, pivot table creation, visualization, and dashboard building.

---

## 📌 Project Objectives

- Understand OTT platform content distribution  
- Perform data cleaning in Excel  
- Extract useful insights with Pivot Tables  
- Build an interactive Excel dashboard  
- Present findings through a PPT and written report  

---

## 📁 Files Included

| File | Description |
|------|-------------|
| **Netflix_Dashboard.xlsx** | Cleaned dataset + helper columns + pivot tables + dashboard |
| **Netflix-OTT-Content-Analysis.pptx** | Presentation used during project evaluation |
| **MINOR PROJECT REPORT.docx** | Detailed analysis report |
| **netflix_datasetss.xlsx** | Sample dataset used for the project |

---

## 📊 Key Insights from the Sample Dataset

- Movies slightly outnumber TV Shows.
- **Action** is the most common genre, followed by Crime, Drama, and Sci-Fi.
- Majority of titles come from the **United States**, followed by **India** and **Spain**.
- Titles in the sample range from release years **2010 to 2022**.

---

## 🛠 Tools Used

- Microsoft Excel (data cleaning, visualization, dashboard)
- Microsoft PowerPoint (presentation)
- Microsoft Word (report writing)

---

## 📈 Dashboard Overview

The dashboard includes:
- Movie vs TV Show distribution (Pie Chart)
- Genre-wise content distribution (Bar Chart)
- Country-wise contribution (Bar Chart)
- Year-wise release pattern (Line/Bar Chart)

The dashboard is fully interactive and updates automatically when the dataset changes.
